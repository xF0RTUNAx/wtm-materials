1. Прочитай fortuna-bot-web/AIRDEF_STATE.md (правила и решения Mark).
2. Возьми изменения: если указан диапазон коммитов — `git diff <диапазон>`, иначе `git diff origin/main -- fortuna-bot-web` плюс
   `git status --short` (новые файлы прочитай). Читай куски, не целиком большие файлы.
3. Ищи по существу:

     `deno run -A tools/airdef-headless/progress-server-test.js` это проверяет);

   - нарушения правил: тронуты запретные файлы, секреты в коде, модели не CC0/CC BY, сильное упрощение моделей;
   - противоречия решениям Mark из AIRDEF_STATE.md.
