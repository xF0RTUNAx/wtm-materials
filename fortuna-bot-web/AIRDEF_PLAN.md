# «Воздушное превосходство» — ПВО мегаполиса против ударной авиации

Отдельная игра рядом с «Симулятором Летки» (`games/drone.html`). Подход тот же: реальная техника с округлёнными
открытыми ТТХ («≈»), игровые параметры масштабированы под арену — это аркада с реальными механиками, а не тренажёр.

Решено с Mark (2026-10-07):
- играть можно **за обе стороны**: одиночка за ПВО (налёты ИИ) и за самолёт (прорыв ИИ-ПВО), потом онлайн ПВО против самолётов;
- ПВО — **карта-командир + «сесть» в любой ЗРК оператором** (экран РЛС + прицел, захват и пуск вручную; остальными управляет расчёт ИИ);
- **все эпохи по уровням**, как УРВВ: от С-75/Hawk и Shrike до С-300/Patriot/«Тор» и JDAM/HARM;
- **сначала одиночка, потом онлайн** (сервер `game-server/` переиспользуем).

## 1. Карта — вымышленный мегаполис
~30×30 км, детерминированный генератор по зерну (один и тот же город у клиента и сервера):
- **Сити** — небоскрёбы 150–400 м, телебашня ~500 м; **спальные районы** — панельные дома 30–80 м;
  **промзона** — НПЗ, ТЭЦ, склады; **порт**, **река с мостами**, **аэропорт/авиабаза**, пригороды и поля по краям.
- **Объекты** — цели с «ценностью» и прочностью (ТЭЦ, НПЗ, мосты, штаб, РЛС, склады, аэродром). Атакующие разрушают,
  ПВО защищает; позиции ПВО — тоже цели (подавление ПВО).
- **Город как механика:** здания закрывают радарам обзор (радиогоризонт + затенение), между небоскрёбами можно лететь
  на малой высоте и прятаться; лазерный луч и телевизор подвесного контейнера тоже заслоняются зданиями;
  столкновение со зданием — гибель.
- Для симуляции — сетка высот застройки (≈20 м), по ней быстрые лучи прямой видимости (работает и на сервере).
- Для графики — инстансинг коробок с процедурными окнами (шейдер), склейка по кварталам, дальние кварталы упрощены;
  ночью — огни города. Пресеты и «Тест графики» — из «Летки».

## 2. Сторона ПВО

### Цепочка боя (как в жизни)
обнаружение (обзорная РЛС) → целеуказание → захват (РЛС сопровождения / оптика) → пуск → наведение → подрыв
(неконтактный взрыватель, радиус поражения) → оценка результата. У каждого комплекса своё **время реакции**, число
**целевых каналов** и **ракет на цель**, **ближняя/дальняя граница** и **высоты** зоны поражения, **перезарядка**.

### Механики наведения ЗУР
- **Радиокомандное** (С-75, С-125, «Оса», Crotale, «Тор», «Панцирь»): ракету ведёт наземная РЛС — потеряла цель
  (затенение, провал, помеха, выключили радар) → ракета летит по инерции. Методы «три точки» (надёжнее, хуже по
  быстрым целям) и «половинное спрямление» (экономнее по энергии).
- **Полуактивное** (Hawk, «Куб», «Бук-М1/М2»): цель нужно **подсвечивать до попадания**; подсвет = занятый канал.
- **Через ракету / TVM** (Patriot PAC-2, С-300): средний участок по командам, конец — по сигналу ГСН ракеты через РЛС.
- **Активное** (PAC-3, NASAMS, «Бук-М3»): после включения ГСН — «выстрелил и забыл».
- **Тепловое** (ПЗРК, «Стрела-10», IRIS-T SLM): не излучает, РЛС не нужна для наведения, против ЛТЦ — по помехозащищённости ГСН.
- **SACLOS / оптика** (Rapier, Roland, оптический канал «Панциря»): радар можно не включать — противорадиолокационная ракета не наведётся.
- **Зенитные пушки** (ЗСУ-23-4 «Шилка», Gepard, пушки «Панциря», Phalanx C-RAM) — по самолётам и по летящим бомбам/ракетам.

### Радар: излучение и его цена
- дальность обнаружения ∝ ЭПР^¼; радиогоризонт; затенение зданиями; у старых РЛС — помехи от земли на малой высоте;
  у импульсно-доплеровских — **доплеровский провал** (цель идёт «траверзом»);
- **включённый радар виден** на станции предупреждения противника и по нему летят противорадиолокационные ракеты;
  выключил — Shrike теряет цель, HARM летит в последнюю точку, ALARM висит на парашюте и ждёт включения;
- помехи с самолёта: «стробы» на экране, дальность самоприкрытия (прожигания); диполи.

### Управление
- **Карта-командир:** расстановка батарей и РЛС перед налётом (бюджет очков), режим излучения (вкл/выкл/мигание),
  приоритеты и сектора, перемещение мобильных комплексов («стрельба и смена позиции»: «Тор», «Панцирь», «Оса» быстро,
  С-300/Patriot — долго).
- **Оператор:** индикатор кругового обзора + индикатор сопровождения, телевизионный/тепловизионный прицел;
  захват, пуск, выбор метода, удержание подсвета. Остальные комплексы ведёт расчёт ИИ.
- Средства РЭБ эпохи III–IV: подавление спутниковой навигации (сбивает JDAM/УМПК), подавление РЛС самолёта.

## 3. Сторона самолёта
«Изделие» из «Летки» с ударной подвеской + **подвесной прицельный контейнер** (обзор, зум, захват точки/площади,
лазерный дальномер-целеуказатель). ИИ-налётчики — самолёты из `models.js` (JET_SPECS).

### Механики ударного оружия
- **Неуправляемое** (ФАБ-500, Mk 82, НАР С-8/Hydra) — прицел CCIP, эпоха I.
- **Лазерное полуактивное** (Paveway I/II/III, КАБ-500Л/1500Л, Х-25МЛ, Х-29Л, AGM-65E): захват точки контейнером,
  сброс в зоне, **подсвечивать до попадания** — держать цель в поле контейнера (ограничения карданов, заслон зданием,
  облака) — самолёт уязвим всё это время.
- **Телевизионное/тепловизионное «выстрелил и забыл»** (Walleye, AGM-65A/B/D, Х-29Т, КАБ-500Кр): **захват до пуска**,
  контраст цели, ночью ТВ хуже ИК.
- **Телекомандное** (Bullpup, Х-23, Х-59 «Овод»): лётчик/оператор ведёт ракету по картинке.
- **Спутниковое** (JDAM, SDB, УМПК, JSOW, Laser JDAM): по координатам, любая погода, не по движущимся (кроме Laser
  JDAM); при подавлении навигации — промах на десятки метров. Планирующие — дальний сброс, но медленные и сбиваемые.
- **Противорадиолокационные** (Shrike, Х-28, HARM, Х-58, Х-31П, ALARM, AARGM): летят на излучение, режимы с памятью.
- **Крылатые ракеты** (Х-59МК2, JASSM, Storm Shadow): малая высота, огибание застройки, малая ЭПР.
- **Ложные цели** (ADM-160 MALD/MALD-J) — перегружают каналы ПВО.
- Защита: станция предупреждения об облучении, ЛТЦ/диполи, станции помех (ALQ-131, «Сирень», «Хибины»), буксируемая ловушка.

### Интерфейс
Зона возможного сброса (LAR) — «в зоне / далеко / близко», время до попадания, подсказка кабрирования;
вид контейнера (палец/мышь ведут прицел); экран предупреждения об облучении с типами РЛС; на «Реализме» без маркеров.

## 5. Режимы
- **«Оборона города»** (за ПВО): волны налётов ИИ нарастают; между волнами — бюджет на новые комплексы и перезарядку;
  победа — город сохранил ≥ N % ценности.
- **«Удар»** (за самолёт): уничтожить заданные объекты против расставленной ИИ-ПВО, вернуться/дожить.
- **Онлайн** (позже): 1–4 ПВО против 1–4 самолётов, ~10 мин, у самолётов возрождение, у ПВО — докупка.

## 6. Устройство кода
- `games/airdef.html` + `games/airdef/*.js`; чистая симуляция без сцены — `games/airdef/sim/` (её же берёт сервер).
- Из «Летки» переиспользуем: `models.js` (M/part/mergeParts/latheZ/buildMissileGeo/buildJet), `post.js`, `audio.js`,
  `sim/core.js` (кинематика, ГСН, PN), пресеты/тест графики/сенсорное управление/настройки, `progress-client.js`,
  `game-server/` (комнаты, журнал). `sim/core.js` сейчас жёстко берёт `terrainH` — сделать землю подменяемой
  (без изменения поведения «Летки»: `regress.sh` должен совпасть с baseline).
- Безголовый прогон как `tools/drone-headless/` — для баланса ЗРК против налётов.
- Версии модулей — та же схема `?v=`.

## 7. Фазы
0. План (этот файл), каркас `airdef.html` (меню, настройки, пресеты), земля в `core.js` подменяемая.
1. **Мегаполис:** генератор, отрисовка с оптимизацией под телефоны, сетка высот для видимости/столкновений; полёт над городом.
2. **За самолёт, одиночка:** ударная подвеска, прицельный контейнер, лазерные/ТВ/неуправляемые/спутниковые; ИИ-ПВО эпох I–II;
   станция предупреждения.
3. **За ПВО, одиночка:** карта-командир, расстановка, оператор (РЛС + прицел), комплексы эпох I–II, налёты ИИ.
4. **Эпохи III–IV + РЭБ:** С-300/«Бук»/«Тор»/«Панцирь»/Patriot/NASAMS/IRIS-T, JDAM/SDB/крылатые, ПРР с памятью, ложные цели,
   помехи и подавление навигации.
5. Баланс, Руководство, прогресс/награды.
6. Онлайн ПВО против самолётов.
