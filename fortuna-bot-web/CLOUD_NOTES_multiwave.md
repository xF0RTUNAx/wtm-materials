# «Мульти-волна»: цены и потолки по измеренной силе — облачная сессия `cloud/multiwave` (2026-10-28)

Задача (Mark 2026-10-25 и 2026-10-28): без рангов и эпох, всё исследованное — в один бюджет, **один бюджет на все бои**,
цена = измеренная сила, потолки «не больше N одного типа», надбавки за ранг нет, первый в ветке — бесплатный стартовый (исследование не меняется).

Макет: `fortuna-bot-web/tools/airdef-ui/multiwave-prices.html` (localhost `:8935/fortuna-bot-web/tools/airdef-ui/multiwave-prices.html`).

## Как мерили (стенд `tools/airdef-headless/multi-price-stand.js`)
Без браузера, как combined-test: бой «волна против ПВО» на «Северном рубеже» по правилам онлайна (sim/combined.js `LIM_ON`, strike `game: 'multi'`,
«Реализм», шаг 0,05 с), наряд как у ботов онлайна (ложные цели — по ПВО, остальное — по трём целям по кругу), 4 потока.
- **Удар** (`atk`, 60 боёв на точку, 4860 боёв): фон — типовая волна ИИ своей стороны (COMBINED[сторона][2…4]) против типовой ПВО противника
  того же уровня (DEFENSE, mission.js placeDefense — как одиночная игра); к фону — m единиц типа (крылатые 4, дроны 6, баллистика 2, «Искандер» /
  «Кинжал» / ARRW 1 — без другой баллистики). **Сила = (ценность, разрушенная волной с ними − без них) / m**, зерно боя одно (расстановка совпадает).
  Объекты на замере неразрушимы: попаданию засчитывается ценность объекта × доля прочности, но не больше объекта (иначе волна по трём целям
  упирается в их ценность — первый прогон показал: добавка «ничего не даёт», потому что цели уже разбиты). Так меряется и «польза» ложных целей и дронов —
  на них ПВО тратит ракеты.
- **ЗРК** (`sam`, 40 боёв в одиночку и 100 в составе, 16800 боёв): типовые волны ИИ уровня 2…4. В одиночку почти любой комплекс выглядит сильным:
  без него дроны долетают (дрон у цели — ≈ 90 ценности), поэтому цена — по вкладу **в составе ослабленной типовой ПВО** (DEFENSE × 0,5): полусумма
  «сбитое им» (кого сбил именно он — по `samEnd` / `gunHit` — × сила этой единицы удара из замера) и «сберёг» (разрушено без него − с ним).
- **Цены** (`price`): удар — ∝ силе, бюджет 100, масштаб подобран так, чтобы волна в среднем разрушала столько же, сколько при нынешних ценах;
  ЗРК — ∝ силе, сумма цен как у нынешних SAM_COST, шаг 10, не дешевле 30. Итог — `tools/airdef-headless/multi-prices.json`.
- **Честность** (`fair`, 150 боёв на строку): случайные «игроцкие» составы на весь бюджет (волна) и на 2500 (ПВО) по ценам, восток бьёт по ПВО запада
  и наоборот; ПВО — как у бота онлайна (целей не знает: дальние между центром и объектами, остальные у объектов); «умные» — берут тип с вероятностью
  ∝ (сила / цена)³. Итог — разрушенная ценность (5 целей, объекты разрушаются).
- **Монопроверка** (`mono`, 30 боёв): вся волна из одного типа (сколько пустит бюджет) или вся ПВО из одного типа — где нужен потолок.
- Носители (Ту-160, B-52, F-16 …) на стенде не сбили ни разу: пуск за краем района, ПВО не достаёт — «с самолёта или с пусковой» на цену не влияет.

| Запад / Восток, разрушено — случайные составы | ×1,01 | ×0,96 |

| Сколько разрушает волна (случайные, 5 целей) | ≈ 585 | ≈ 570 |
Ошибка ±2–3 %. Монопроверка без потолков: 40 дронов — ×1,6–1,7 от смешанной волны, 20 дешёвых крылатых Запада (AGM-86, Storm Shadow) — ×1,5–1,6;
ПВО из одного типа нигде заметно не сильнее смешанной (лучшая — «Оса» ×0,86, Roland ×0,95).

Наблюдения: крылатые Востока против ПВО Запада сильнее, чем крылатые Запада против ПВО Востока («Тор», «Панцирь», «Тунгуска», «Оса» хорошо
бьют по маловысотным) — поэтому цены разные; ближние ЗРК Запада (Gepard, Stinger, Avenger, Skyguard, Rapier) сильны почти только против дронов —
по крылатым на 30–60 м почти не стреляют; «Стрела-1», ЗУ-23, «Шилка», Redeye в «Мульти-волне» почти ничего не дают; **РЭБ (подавление GPS)
действует только на авиабомбы с GPS — на крылатые и баллистику «Мульти-волны» нет** (sim/strike.js: `W.kind === 'gps'`).
Сила по уровням ПВО сильно скачет у части ракет (Х-555: 129 / 44 / 166) — выбор под ПВО противника остаётся.

## Как пересчитать (новые единицы)
```
deno run -A tools/airdef-headless/multi-price-stand.js atk N=60     # ≈ 20 мин на 4 ядрах → multi-price-atk.json
ATK=tools/airdef-headless/multi-price-atk.json deno run -A tools/airdef-headless/multi-price-stand.js sam N=40 NA=100   # ≈ 45 мин
deno run -A tools/airdef-headless/multi-price-stand.js price        # → multi-prices.json
deno run -A tools/airdef-headless/multi-price-stand.js fair N=150   # Запад / Восток
deno run -A tools/airdef-headless/multi-price-stand.js mono N=30    # где нужен потолок
```
`CACHE=файл.jsonl` — продолжить оборванный прогон (облачный контейнер один раз перезапустился посреди замера). Нужен `tools/drone-headless/three.min.js` (three 0.128.0).
