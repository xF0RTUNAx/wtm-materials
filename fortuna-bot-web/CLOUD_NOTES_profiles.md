# Облачная сессия: профили игроков (ветка `cloud/profiles`, 2026-10-28)

Задача 2 из списка Mark (2026-10-25): профиль игрока открывается из таблицы рейтинга (свой — из своей карточки): ник аккаунта игры, статистика
по режимам, лучшие бои сезона, любимые самолёт и ЗРК, награды. Никаких id наружу.
Макет (одобрен, с решениями): `tools/airdef-ui/profile-mock.html` (он же — https://claude.ai/artifact/MdBbV9WjGseSt6GoRcyzSj).

## Решения Mark (28.10, ответы на 7 вопросов макета)
1. Одиночные бои — не показывать, только онлайн.
2. Период — «Сезон N» и «Всё время» (переключатель).
3. Любимые самолёт и ЗРК — только онлайн.
4. Награды — только места за сезоны.
5. Кнопка «скрыть мою статистику» — не нужна.
6. Стрелка «›» в строках рейтинга — оставить.
7. Чужие лучшие бои — без разбора очков.

Моё решение (сказать Mark): самолёт считается по своим вылетам (лётчик «Вылета и обороны»); в «Мульти-волне» налёт ведёт ИИ — его самолёты
не считаем, там идут в счёт только ЗРК (раунды за ПВО). ЗРК — «в скольких боях стоял» (стоял к началу волны, проданные на расстановке не в счёт).

## Что сделано
- **Сервер ноутбука** (`game-server/airdef-own.js` useOf / useOut, `airdef-rooms.js`, `airdef-multi.js`): в подписанный итог боя — поле
  `u: { fl: { самолёт: вылетов }, sm: [ЗРК] }` (нет ни того, ни другого — поля нет). Вылет — каждый выход человека на самолёте (подхват
  ИИ-двойника после обрыва — не вылет); ЗРК — комплексы игрока, живые к началу волны (раунда). `airdef-claim` менять не надо: итог и так
  целиком ложится в `airdef_mp_results.result`.
- **База** `sql/029_airdef_profile.sql`: `airdef_profile(p_nick, p_season)` → jsonb: ник, «в игре с», онлайн-боёв, место / очки / засчитано
  (как `airdef_rating_board`), по режимам (вылет / оборона / «Мульти-волна») за сезон (по времени боя в границах сезона, с боями своих
  комнат) и за всё время — боёв, побед, поражено, лучший бой; любимое за сезон и за всё время из `result.u` (чужие ключи и числа отброшены);
  лучшие бои сезона (`airdef_rating_counted`, без разбора и номера боя); места за сезоны (`airdef_season_paid`). Права — только service_role.
- **Функция** `supabase/functions/get-airdef-profile` (новая): `{ nick, season? }` → `{ season, live, profile }`, 404 — нет такого игрока.
  Профиль ищется по нику (без учёта регистра); ни id игрока, ни номеров боёв в ответе нет. Сезон выбирается как в get-airdef-rating.
- **Клиент** `games/airdef/rating-ui.js`: строки таблицы — кнопки со стрелкой «›» → профиль в том же окне, «Назад» — к таблице (прокрутка
  таблицы сохраняется); свой ник в карточке (подчёркнут точками) → свой профиль с кнопкой «Мои бои». Вид: шапка (значок из ника, место
  с кубком у тройки), «По режимам» с переключателем, «Любимое» (рендеры из `airdef/thumbs`, имена из NODE), «Лучшие бои сезона», «Награды».
  В горизонтали телефона (высота ≤ 500 px) — две колонки, каждая листается сама. Кэш профиля — минута.
  `games/airdef/account.js`: `profile(nick, season)` и заглушка `?rmock=1` (`mockProfile`; у первых 12 мест — пример наград);
  `lang/en-ui.js` — английские тексты (сканер `tools/i18n/scan.js` — без пропусков).
- **Тесты:** новый `tools/airdef-headless/profile-sql-test.js` (PGlite: поиск по нику, режимы, любимое, испорченное `u`, лучшие бои,
  награды, нет id, новичок, другой сезон, права); проверки поля `u` в `game-server/airdef-full.js` и `airdef-multi-test.js`.
