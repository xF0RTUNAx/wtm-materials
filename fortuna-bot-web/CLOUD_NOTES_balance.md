# Баланс удара по объектам — облачная сессия `cloud/strike-balance` (2026-10-29 … 2026-11-01)

Задача Mark (2026-10-29): «Провести различные тесты, расчёты и т. д., чтобы создать баланс между каждой бомбой и ракетой, которая наносит урон
по объектам, и как-то это систематизировать. Чтобы у каждой бомбы был какой-то эквивалент и был смысл качать бомбы дальше и выбирать
соответствующие в готовых сборках. А разрушения будут иметь просто визуальный характер: обычное вооружение будет активировать анимацию
разрушения для области, в которой был нанесён урон, а управляемое — сможет как раз точечно выбирать один из разрушаемых объектов, но наносить
эквивалентный импакт по сути. Чтобы это всё было сбалансировано, чтобы объекты не разрушались слишком быстро, но и не слишком долго».

**Состояние: этап 2 сделан — в игре, тесты прошли в облаке. Ждёт проверки главной сессией на Маке (ui-test, телефон) и деплоя по слову Mark.**
Ветка влита с online-dev 6caf37d (сеть ПВО против летящего оружия и самоликвидатор ЗУР уже учтены в замерах).

## Что сделано (по файлам)
- **arsenal.js** — `eqOf(W)`: эквивалент, урон по объекту прямым попаданием в ЕУ (ФАБ-500 = 100), `E = 100 · R / 47` до 5; поле `eq` —
  исключения: С-8 и Hydra 8 (с самолёта `planeEq` 5), ОФАБ-250 80, GBU-57 250, JASSM 90, Х-59МК2 100. `loadoutEq(L)` — сила подвески
  (ПРР, помехи и ложные цели не считаются; НАР — ракет в блоках), `loadoutTargets(L)` — целей «Вылета»: round(сила / 300), от 1 до 3
  (`STRIKE_TGT_EU`). `dmg` / `blast` не менялись — урон по ЗРК и технике прежний.
- **sim/strike.js** — `blast(…, eq, guided)`: объекту — eq × близость (прямое попадание — eq, рядом — 0,8 eq (1 − d/R)^0,6, площадка ×0,4);
  без eq — как раньше (eq = dmg · 1,25: стенды с «голым» уроном считают по-старому). Гибель — **только по общей прочности**
  (`bldMainsDead` больше не убивает). Постройки — вид: неуправляемое (свободные бомбы, НАР, баллистика с КВО больше 30 м — Р-17, «Точка-У»,
  Lance) — каждая в радиусе копит свою долю, как раньше; управляемое (`guidedOf`: ГСН, спутник, ракеты, крылатые, дроны, точная баллистика)
  — только постройка под прицелом: ближняя по горизонтали, над несколькими сразу — выше (вагоны эшелона цистерн и эстакада между ними).
  НАР с самолёта — `planeEq`.
- **city.js** `OBJ_HP` — прочность по размеру: малый 150 (две РЛС, узел связи, вертолётная площадка), средний 200 (склады, парки, городки,
  гарнизон, рембаза), укреплённый 250 (три КП), крупный 300 (аэродром, авиабаза, ГЭС, ж/д узел, ВМБ); **map-winter.js, map-autumn.js** — так же.
- **air.js** — целей «Вылета» по силе подвески (`game.tgtN`; «Операция» — по подвеске второго вылета; охота за ПВО и обучение — 3, как было);
  брифинг: «Цели (N — по силе подвески): …»; опыт за цели — вес 3 / N на цель (выполненное задание — как прежние 3 цели при любом N,
  иначе слабые подвески ранга I качались бы втрое медленнее). **menu.js / airdef.html** — в кнопке подвески строка «целей: N — по силе подвески».
- **sim/raid.js** — (1) `spawnWave`: пара (одно направление) — одна цель, пары по целям по очереди (было `(i + g) % 2` — при 2 целях и
  3–4 самолётах все шли на первую); (2) лазерные и ТВ-бомбы — сброс, только если ГСН видит точку сразу после сброса (лазерная — в поле
  зрения, ТВ — вдвое шире, запас 0,8), иначе новый заход издалека (`reattack` — до 2,6 высоты).
- **defense.js** — прогноз наряда «≈ % разрушит» — по эквиваленту. **training.js** — учебные цели: демо — eqOf × 0,25 (с одного попадания),
  вертолётные уроки — доля прочности 0,14 / 0,2 (было 0,25 / 0,2 / 0,35): попаданий ПТУР и НАР столько же, сколько раньше.
- **progress.js** — досье оружия: «Удар (ФАБ-500 = 100)» вместо «Урон» (у ПРР — «Урон»). **guide.js** — абзац «Сколько целей» во «Вылете»
  и «удар N» у каждого оружия. **lang/en-*.js** — английские строки (dict-check: ошибок 0).
- Копии для функций базы — `sync-shared.js` (arsenal.js, progress.js в `_shared/airdef`).
- **Тесты:** aim-test — по настоящему оружию с эквивалентом; site-test — «разбиты все главные при запасе прочности — объект цел»,
  до 4 ПТУР на главную, новая проверка «ФАБ-500 разбивает область, КАБ-500С с тем же эквивалентом — только резервуар под прицелом».
