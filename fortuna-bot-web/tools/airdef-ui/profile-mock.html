Профиль игрока

Сделано в ветке cloud/profiles, как в этом макете. Профиль открывается из таблицы рейтинга: нажатие на строку игрока. Свой — нажатием на свой ник в карточке внизу. Окно то же, что у рейтинга: профиль встаёт на место таблицы, «Назад» возвращает к ней. Ники и цифры — пример.

Окно в игре

Профиль, таблица и свой профиль

  • Шапка: значок из ника (фото нет — у аккаунта игры свой вход, не Telegram), ник, когда завёл аккаунт, место в сезоне и очки. Топ-3 — цветом места, как в таблице.
  • «По режимам» — онлайн-бои: сколько, побед и их доля, поражено (у лётчика — уничтоженные ЗРК, у ПВО — сбитые), лучший бой по очкам рейтинга.
  • «Любимое» — только онлайн: самолёт, на котором больше всего вылетов, и ЗРК, стоявший в большем числе боёв. В «Мульти-волне» налёт ведёт ИИ, там считаются только ЗРК. Картинки — те же, что в «Исследованиях».
  • «Лучшие бои сезона» — засчитанные бои (2 + 2 + 2 + 1), без разбора очков. Разбор остаётся только в своих «Моих боях».
  • «Награды» — только места за прошедшие сезоны (кубок цвета места, топ-10 — звезда). Первый сезон идёт до 01.01.2027, поэтому сейчас там пусто; ниже пунктиром — как будет.
  • В своём профиле — кнопка «Мои бои» и строка «так вас видят другие».

Решения Mark, 28.10.2026

Что решили

  1. Одиночные бои — не показываем, только онлайн.
  2. Период — переключатель «Сезон N / Всё время».
  3. Любимые самолёт и ЗРК — только онлайн, записываем с обновления сервера.
  4. Награды — только места за сезоны.
  5. Скрыть профиль — не нужно.
  6. Стрелка «›» в строках рейтинга — оставляем.
  7. Чужие лучшие бои — без разбора очков.
