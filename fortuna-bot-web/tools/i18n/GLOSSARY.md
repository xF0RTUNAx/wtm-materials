# Глоссарий перевода «Воздушного превосходства» (RU → EN)

Решения Mark 2026-10-21: названия карт и целей — по смыслу; советская/российская техника — латиницей (как в англоязычных
источниках), западная — оригинальные названия. Стиль — короткий, как в мобильных играх, без канцелярита; кнопки — заглавными,
если в русском заглавные.
