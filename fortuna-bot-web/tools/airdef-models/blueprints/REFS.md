# Справочники для собственных моделей «Воздушного превосходства»

Дата сбора: 2026-10-21. Собрано поиском в открытых источниках. Ничего не скачано, ничего в репозитории не изменено (этот файл — единственный новый).

Правила, которыми пользовался:
- Чертежи и фото из игр (War Thunder, DCS и т. п.) не используются. Форум War Thunder попадался в выдаче, но как источник размеров не брался.
- Числа берутся из нескольких источников, расхождения указаны явно.
- Лицензия: «PD» — public domain (правительство США и т. п.), «CC» — Creative Commons, «©» — полные права у владельца, «?» — не выяснено.

**Что явно готово к моделированию:** Р-77 (размеры полные; схема вариантов есть). Остальные — только размеры; профильный чертёж надо найти или сделать самим по размерам (это вполне подходит для собственной модели: корпус — тела вращения, плоскости — пластины).

**Главный пробел:** ни для одного изделия не найдено подтверждённого public-domain чертежа в трёх проекциях. Официальные американские материалы (af.mil, navair, DVIDS) дают фото и тексты с размерами, но не размерные чертежи. Размерные схемы придётся либо собрать из нескольких справок, либо построить по размерам без подложки.

## Заметки для моделирования: общие правила

- Корпус ракеты — тело вращения (revolve) по профилю: нос + цилиндр + хвостовой конус. Так получается 80–120 треугольников на корпус.
- Плоскости и рули — пластины (box или plane с толщиной), повторить по 4 штуки. Решётчатые рули Р-77 — упрощённо рамки, без полной сетки.
- Сопла — цилиндры малой высоты, спец-форма не нужна.
- Бомба — тело вращения + отдельные пластины стабилизатора (Paveway III — крестообразный блок).
- Полигоны (ориентиры из задания): ракета 300–800, бомба 400–1 200, крылатая ракета 800–1 200.
- Размеры в метрах, ось Z — по длине (как в prepare.js, проверить при подготовке).
