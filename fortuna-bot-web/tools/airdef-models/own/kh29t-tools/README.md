# Х-29Т — сборка модели (Blender 5.2, blender-mcp)

Модель собрана по картинкам Mark (`~/Downloads/Воздушное превосходство/Модели/Свои/Х-29Т/1–7.png`: два вида сбоку, спереди, сзади, окраска).
Масштаб — длина 3,896 м, как у прежней модели в игре; все размеры в `build.py` — в пикселях чертежа 4.png (нос слева), множитель `S`.

- `build.py` — строит сцену `KH29T` (коллекция `KH29T`): корпус вращением со швами, четыре крыла и рули крестом, накладки по цилиндру,
  кожух снизу, проушины сверху, купол головки. Запуск в Blender: `exec(compile(open(путь).read(), путь, 'exec'))`. Нос +Y, начало — середина длины.
- `render_views.py` — силуэты модели в размерах кадра чертежей (`K29_OUT` — рабочая папка с `ref/` и `out/`); `compare.py` — наложение на чертёж и IoU
  (бок 0,96 на последней сборке). Нужен Pillow (`/usr/bin/python3 -I`, путь к пользовательским пакетам добавляется в скрипте).
- `grid.py` — увеличенные куски чертежа с сеткой координат (снимать размеры).
- Экспорт: выбрать объекты `K29_*`, `export_scene.gltf` (GLB, Y вверх) → `../kh29t.glb`; `.blend` — `bpy.data.libraries.write` коллекции. Дальше — по рецепту
  в AIRDEF_STATE.md («Blender»): запись в prepare.js (`own: true`) → `prepare.js w_kh29t` → GLB_V в models.js → `thumbs-bake.js wpn:kh29t`.
- Материалы: `K29_body` (корпус), `K29_wing` (крылья, рули, лючки), `K29_ctrl` (рули на задней кромке, кожух), `K29_dark` (швы, купол, сопло); цвета — в `build.py`
  (`mk(...)`) или переопределить в prepare.js через `colors`.
