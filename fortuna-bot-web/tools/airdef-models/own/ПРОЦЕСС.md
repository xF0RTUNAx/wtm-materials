# Свои модели оружия — процесс «только форма»

Зачем: в игре уже есть эти ракеты и бомбы (arsenal.js, models.js), но часть моделей взята с признаками игровых рипов
(список — AIRDEF_STATE.md, «Открытые задачи»). Нужны свои, внешне достоверные модели. Это работа моделиста-макетчика:
повторить **внешний вид** по открытым фотографиям и габаритам. Больше ничего не нужно.

Hydra 70 и С-8КОМ (own/hydra70.*, own/s8.*) сделаны ровно так и прошли без остановок. Остановки 2026-10-21 случались
на другом — на разборе **справочных данных** (схемы, устройство, характеристики) управляемых ракет и ЗРК. Поэтому:

## Правило одной строки
**В задание и в чат попадают только внешность и размеры. Ни устройства, ни назначения, ни характеристик — даже если они
«и так в игре».** Что ракета делает, игра уже знает из arsenal.js; моделисту это не нужно.

## Что собираем по каждой модели (папка `~/Downloads/Воздушное превосходство/Модели/Свои/<ключ>/`)
- `ref-side.jpg` (вид сбоку), по возможности `ref-front.jpg` / трёхвидовой чертёж **внешних обводов**. Источники: Wikimedia
  Commons, музейные и выставочные фото, фото с авиасалонов. Лицензия — CC0 / CC BY / PD; записать ссылку и автора в `ИСТОЧНИКИ.txt`.
- `РАЗМЕРЫ.txt`: длина, диаметр корпуса, размах крыльев и рулей, число и расположение плоскостей, форма носа (оживало / конус /
  прозрачный обтекатель / плоский), заметные детали снаружи (стыки, пояса, лючки, сопло), окраска (цвет корпуса, полосы, надписи — как
  на фото). Всё это — из фото и открытых габаритов с той же страницы Wikimedia; дальше не копать.
- Больше ничего. Ссылки на статьи «про ракету» в задание не вставлять.

## Кто делает
- **Разведчик (`airdef-scout`)** — только поиск картинок: «найти фото сбоку / трёхвидовой чертёж внешних обводов <название>
  с лицензией CC0/CC BY/PD, вернуть ссылку, автора, лицензию, видимые на фото габариты». Запрет в задании: не собирать и не
  пересказывать устройство, характеристики, применение.
- **Строитель** — главная сессия с Blender (blender-mcp) или `airdef-worker` скриптом bpy по рецепту ниже. Задание содержит
  только: ключ, путь к папке с фото и `РАЗМЕРЫ.txt`, рецепт, куда положить результат, как проверить.
- **Mark** — смотрит рендер и снимок в стенде, решает «похоже / не похоже», выкладывает на Sketchfab (CC BY) с текстом из папки.

## Рецепт сборки (Blender, как у Hydra 70 и С-8)
1. Фото сбоку — фоновой картинкой (Image as Plane / background), масштаб по известной длине.
2. Корпус — профиль вращения (bmesh `spin` по точкам силуэта): нос, цилиндр, стыки и пояса как ступеньки профиля, хвост и срез сопла.
3. Крылья и рули — плоские пластины по силуэту (толщина 2–4 % хорды), размножить по числу плоскостей (array/rotate), стреловидность
   и положение по фото.
4. Мелочь снаружи (антенны, лючки, полозья) — только то, что видно на снимке с 10 м; остальное не нужно.
5. Цвет — вершинный или одна текстура ≤ 256 px: цвет корпуса, полосы и надписи условно (без точной маркировки).
6. Бюджет: 2–6 тыс. треугольников, GLB ≤ 150 КБ. Ось: нос по −Z (как у `w_nar_*`), начало координат — центр длины.
7. Сохранить `own/<ключ>.blend` и экспорт glTF `own/<ключ>.glb`.

## Встраивание (как в AIRDEF_STATE.md, «Blender»)
`prepare.js` — запись `w_<ключ>: { src: new URL('./own/<ключ>.glb', import.meta.url).pathname, scale: 1, nose: '-z', tex: () => 256,
pickMesh: /./, own: true }` → `deno run -A tools/airdef-models/prepare.js w_<ключ>` → META и GLB_V в models.js (ключ уже есть у
старой модели — поднять версию) → авторы в кредитах models.js («своя модель») → миниатюра `deno run -A tools/airdef-headless/thumbs-bake.js
wpn:<ключ>` (сервер :8935) → факел и сопло: `tools/airdef-fx/weapons-plume.html` / `weapons-plume-shots.js <метка> only=<ключ>` →
снимок Mark → ui-test → коммит, пуш в online-dev. Старый файл модели — в «Отклонённые (рипы из игр)».

## Порядок (по заметности в игре; решение Mark)
1. Ракеты «воздух–земля» и бомбы — профиль вращения + пластины, самое простое: Х-29Т, Х-31П, GBU-24, GBU-57, Storm Shadow
   (корпус с гранями — коробка со скосами вместо вращения).
2. Ракеты «воздух–воздух» Rhine_Lab (Р-73/77/27/33, AIM-7, AIM-9X) — та же схема.
3. ЗРК и зенитки на шасси (Бук-М3, Оса-АКМ, Gepard, Панцирь, Хордад) — профилем не сделать: либо `generate_3d` в Blender по фото
   (image-to-3D, одна модель за 1–3 мин, может стоить кредит) с чисткой, либо покупка модели с явной лицензией (покупает Mark),
   либо готовая CC-модель (Gepard — `flakepanzer_gepard_model.glb`, diablomj, ждёт слова Mark).
