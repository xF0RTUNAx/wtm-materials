«Своя комната»: варианты

Mark 2026-11-17: «давай еще настроим дизайн своей комнаты - тоже предложи мне несколько дизайнов». У каждого варианта два кадра: создание комнаты (после «Своя комната» в «Онлайне») и сама комната - код, приглашение, две команды, готовность. Сейчас это строки кнопок «Формат / Ранг / Авиация / Пустые места» и списки ников текстом. Пример: 2×2, ранг II, вы - хост в авиации, одно место у ПВО свободно («+ бот» - только у хоста).

А · «Табло команд»

Создание формат плитками, сторона значками, боты - переключателем
Комната код крупно, команды двумя табло, лампы готовности, пустое место - «+ бот»

Б · «Карточки игроков»

Создание формат «− 2×2 +», сторона авиации картинками
Комната каждый игрок - карточка с аватаркой, готовые подчёркнуты зелёным

В · «Ангарные таблички»

Создание настройки крупными клетками на табличке
Комната код на бирке, команды - таблички с местами-аватарками
