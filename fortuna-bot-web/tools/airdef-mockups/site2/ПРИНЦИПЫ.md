# Сайт airsuperiorityonline.com — принципы (исследование 2026-11-18)

Mark отверг макеты site/a,b,c: «очень по ИИшному, не забывай рекомендации по шрифтам, отказ от нумерования».

## Признаки «ИИ-сайта» — избегать
- Inter/системный шрифт и больше ничего; фиолетово-синие градиенты; стекло; бенто-сетки; одинаковые карточки, отступы, скругления.
- Надзаголовок мелким капсом над каждым заголовком; каждый раздел по шаблону «метка, заголовок, абзац, 3 карточки».
- Нумерация разделов (01/02/03), тематический реквизит (штампы, скотч, миллиметровка, трафарет, коды, позывные, моноширинные «технические» подписи).
- Капс везде; иконки в кружках; эмодзи; выдуманные счётчики; всё по центру; свечение, неон; несколько акцентов.
- Мало кадров игры, много декора; одинаковое появление (fade-in) каждого блока; автокарусели.

## Принципы
1. Кадр из игры — главный элемент (больше половины площади главной).
2. Одна гарнитура (или пара заголовки+текст), 2–3 начертания; иерархия — кеглем и весом. Хорошая кириллица.
3. Шкала: десктоп 56–72 / 32–40 / 20–24 / 17–18 px; телефон ≈ 36 / 26 / 20 / 16.
4. Межстрочный: текст 1,5–1,6; крупные заголовки 1,05–1,2, лёгкая отрицательная разрядка.
5. Колонка текста 560–680 px (60–75 знаков).
6. Обычный регистр заголовков (sentence case). Капс — только метки/кнопки до 2–3 слов, разрядка +5–10 %.
7. Ничего не нумеровать на главной (в документах функциональная нумерация допустима).
8. Три фичи разной формы (одна во всю ширину, две в паре), не 6 одинаковых карточек.
9. Тексты конкретные: названия техники, что делает игрок; 1–2 фразы на блок, без лозунгов.
10. Цвет: тёмная слегка окрашенная гамма + один акцент для кнопки «Играть». Без декоративных градиентов.
11. Текст на кадре — затемнение снизу/сбоку, контраст ≥ 4,5:1.
12. Движение: только фоновое видео/кадр в первом экране (с паузой) и реакция кнопок. Без анимаций каждого блока и автокаруселей.
13. Отступы между разделами 120–160 px (десктоп), внутри блока заметно меньше.
14. Одна главная кнопка, дважды: первый экран и конец страницы; остальное — текстовые ссылки.
15. Подвал: документы, поддержка, соцсети, копирайт, возраст, оговорка о товарных знаках техники.

## Схемы главной
1. Кинематографичная (Valorant, Silksong, MSFS): видео/кадр на весь экран + одна строка + кнопка → одна крупная фраза → 3 фичи с чередованием кадр слева/справа → галерея 6–8 кадров (ручная) → где играть + кнопка → подвал.
2. Живая игра (War Thunder, Supercell): событие/обновление → 3 новости → об игре + режимы крупными кадрами → трейлер → сообщество → подвал.
3. Компактная студийная (Hades II, Sky): широкий арт → «об игре» 1–2 фразы + платформы + кнопка → (отзывы, если реальные) → галерея 8–12 → медиа → подвал.

## Документы (Riot, Supercell, Gaijin)
Простая колонка (≈ 600–790 px), дата у заголовка, липкое оглавление с якорями, разделы можно нумеровать, короткое резюме раздела простым языком, ссылки на соседние документы, без картинок (максимум тонкая полоса арта в шапке).
