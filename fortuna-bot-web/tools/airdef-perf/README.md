# Стенды производительности «Воздушного превосходства» (2026-10-23)
Chrome без окна (видеокарта Мака, `--use-angle=metal`), телефон в горизонтали (`?touch=1`, 915×412, dpr 2–2,625); локальный сервер — http://127.0.0.1:8937 (корень — wtm-materials).
Запуск из любой папки: `deno run -A <стенд> …` (puppeteer-core 22.15, Chrome — /Applications/Google Chrome.app). Результаты пишутся рядом с текущей папкой.
- `profile-ab.js <пресет> [с] [карта] [игра]` — профиль ЦП по функциям, к/с, вызовы; `PORT=8938` — копия «до» (git archive <коммит> fortuna-bot-web/games fortuna-bot-web/config.js в папку, `python3 -m http.server 8938`).
- `breakdown.js <пресет> [карта]` — вызовы отрисовки по группам сцены (тени отдельно); `SHOT=файл.png` — снимок.
- `mem-check.js <пресет> [карта]` — видеопамять текстур по видам (модели / эффекты / земля / KTX2), геометрия, JS.
- `far-ab.js <пресет> [карта]` — дальние копии объектов до (`?farflat=0`) и после: снимки с реального расстояния и телевиком, вызовы на копию.
- `ex-shot.js <R> <kind> [пресет] [дистанция]` — взрыв в игре: новый лист против прежнего (`?exnew=0`), серия кадров с боковой камеры.
- `cap-test.js` — предел кадров на 60/90/120/144 Гц; `pr-check.js` — чёткость (pixelRatio) по пресетам; `vc-check.js` — у всех сеток с цветом вершин есть атрибут color; `sw-test2.js` — сервис-воркер и кэш моделей (`?sw=1`).
- `ctx-restore.js` — потеря контекста WebGL в бою на телефоне: снимки до / после и счёт пустых текстур KTX2 (ktx.js ktxRestore — земля, деревья, листы взрывов, модели не чернеют).
- `ex-reel.js` — ролик всех взрывов в игре (пожар — в 2,5 раза дольше: петля без шва).
- 2026-10-25 — замеры видеокарты по таймеру (нужен флаг Chrome `--enable-privileged-webgl-extensions`, в стендах есть):
  - `compare-builds.js <пресет> <карта> <pr,pr,…> [круги]` — три сборки во вкладках рядом (до оптимизации :8941, на сайте :8942, сейчас :8937), по очереди,
    одинаковые виды и разрешения, видеокарта занята ≥ 40 мс на замер (иначе лёгкий кадр сбрасывает частоту, разброс ±40 %); сводка — `compare-builds-sum.py`,
    итог 2026-10-25 — `compare-builds-2026-10-25.jsonl`.
  - `frame-ab.js <карта> [пресет]` (VARS — варианты: порядок земли, порог, анизотропия), `ground-ab.js <карта> [пресет]` (только земля, SHOTS — снимки),
    `post-ab.js [пресет] [карта]` (только постобработка: FXAA+CAS одним проходом или двумя) — варианты переключаются на одной странице, по очереди.
  - Раздельные запуски страниц (старая сборка в одном, новая в другом) на батарее — шум ±10 %: сравнивать только по очереди в одной сессии браузера.
